Pha 1 · Bước 1

Data Ingestion — Crossref API

Luồng xử lý

  • Gọi Crossref Works API với query, filter theo pub-date & abstract
  • Retry backoff tự động (tối đa 5 lần) cho lỗi 429/503
  • Parse response → PaperRecord (doi, title, summary, authors, categories, published)
  • Lưu raw response JSON + raw records JSON vào data/raw/

📌 Paper Record Schema

paper_id · title · summary · authors · categories · published · updated · abs_url · pdf_url

# Crossref API endpoint
CROSSREF_API_URL = "https://api.crossref.org/works"

# Query parameters
query: "artificial intelligence"
rows: 50
sort: "published"
order: "desc"
filter: "has-abstract:true"

# Output artifacts
📄 data/raw/crossref_response.json
📄 data/raw/crossref_records.json

paper_id = lowercase DOI → stable, unique, traceable qua toàn bộ pipeline

Pha 1 · Bước 2

Data Cleaning & Modeling

Quy trình làm sạch

  • Chuẩn hóa Unicode NFKC, strip HTML markup, loại bỏ whitespace dư
  • Lọc bỏ: thiếu ID, title rỗng, summary < 100 ký tự, ngày không hợp lệ
  • Deduplicate theo paper_id (lowercase DOI)
  • Tính age_days = (today − published date)
  • Build text_for_embedding = Title + Authors + Summary

11 Loại Data Corruption — Định Nghĩa

# Loại lỗi Định nghĩa Chiều bị tấn công
1 🗑️ Drop Latest Xóa hoàn toàn 10% bài báo mới nhất khỏi dataset → agent không thể tìm thấy Completeness
2 📝 Blank Summary Xóa trắng trường summary → chuỗi rỗng "", agent tìm được bài nhưng không có nội dung Completeness
3 🔀 Inject Noise Chèn text rác [CORRUPTED-NOISE] vào cuối abstract → embedding nhiễu, retrieval sai lệch Accuracy
4 ✂️ Truncate Title Cắt tiêu đề còn 24 ký tự → exact-match thất bại, dense retrieval suy giảm Accuracy
5 📅 Make Stale Đẩy published lùi 730 ngày → vi phạm freshness threshold 180 ngày → quality FAIL Freshness
6 🔄 Swap Categories Tráo categories giữa 2 bài → bài AI lấy category Oil & Gas → agent trả lời sai chủ đề Consistency
7 👥 Swap Authors Tráo authors giữa 2 bài → câu hỏi "Who authored?" trả lời sai tác giả Consistency
8 🏷️ HTML Leakage Chèn thẻ HTML thô <i>...</i> vào abstract → mô phỏng lỗi ETL khi HTML chưa strip sạch Accuracy
9 ⏰ Future Date Đẩy published tới +365 ngày trong tương lai → age_days âm → dữ liệu phi logic Freshness
10 📋 Duplicate Row Sao chép y nguyên 1 bài → 2 dòng cùng paper_id → vi phạm uniqueness, kết quả trùng lặp Uniqueness
11 🪞 Near-Duplicate Tạo bản sao gần giống: thêm "(replicated study)" vào title, đổi ID → khó phát hiện hơn exact dup Uniqueness

Kết luận

Key Takeaways

  • 1 Data Quality = Agent Quality
    Dữ liệu bẩn trực tiếp làm giảm Hit Rate từ 100% → 33.3%, F1 từ 1.0 → 0.46
  • 2 Observability phải có từ đầu
    Quality checks & freshness monitoring phát hiện vấn đề trước khi người dùng nhận câu trả lời sai
  • 3 Raw artifacts = bảo hiểm
    Lưu raw response trước mọi biến đổi → có thể repair & phục hồi hoàn toàn từ nguồn tin cậy
  • 4 So sánh bằng metrics, không bằng cảm tính
    Cùng test set, cùng evaluator → 3 trạng thái đối chiếu minh bạch, có evidence
